# PriceSentry

PriceSentry is a near real-time competitor price intelligence system built to track pricing across multiple sources, detect market movement, and help businesses make faster pricing decisions.

It combines web data collection, structured processing, and interactive dashboarding into a single workflow that is easy to monitor and scale.

## What it does

- Tracks competitor prices across multiple websites.
- Detects price drops and discount trends.
- Highlights hot deals automatically.
- Compares products source-wise.
- Shows clean insights in a Streamlit dashboard.
- Helps businesses react faster to market changes.

## Why it matters

Manual competitor tracking is slow, repetitive, and error-prone.

PriceSentry solves this by automating the full process so teams can spend less time collecting data and more time acting on it.

## Key features

- Source-wise price tracking.
- KPI cards for quick summary.
- Average price comparison charts.
- Discount distribution analysis.
- Hot deals section.
- Searchable product table.
- Filters for source and discount range.
- Refresh support for updated data.
- Clean dark dashboard UI.
- Reusable structure for different datasets.

## How it works

1. Data is collected from target websites.
2. Raw values are cleaned and normalized.
3. Prices and discounts are calculated.
4. Insights are displayed in charts and tables.
5. Users review trends and take action.
